# Лабораторная работа №7

## Детектирование объектов и сегментация изображений. YOLO

В лабораторной реализована система подсчета автомобилей на видео с помощью модели YOLO26 из Ultralytics.

Исходное видео лежит в папке проекта и называeтся:

```text
traffic.mp4
```

Запуск:

```powershell
py object_counter.py --source traffic.mp4
```

Результаты сохраняются в папку:

```text
runs
```

После запуска там появляются:

- `counted_video.mp4` - видео с рамками, ID объектов, линией подсчета и итоговым счетчиком;
- `count_events.csv` - таблица событий, где записаны посчитанные объекты.

## Что происходит в программе

Программа считывает видео покадрово через OpenCV. Для каждого кадра модель YOLO26 находит транспортные средства: `car`, `motorcycle`, `bus`, `truck`. Затем трекер ByteTrack связывает найденные объекты между кадрами и присваивает каждому объекту постоянный ID.

По умолчанию используется режим подсчета по линии. На кадре рисуется контрольная линия. Когда центр объекта пересекает эту линию, объект засчитывается один раз. Это позволяет считать автомобили в потоке и не учитывать один и тот же автомобиль много раз.

## Суть методов

YOLO выполняет детектирование объектов. Нейросеть получает изображение и возвращает координаты рамок объектов, класс объекта и уверенность модели.

Сегментация отличается тем, что модель может возвращать не только прямоугольную рамку, но и маску объекта. В программе поддерживаются сегментационные веса, например `yolo26n-seg.pt`.

ByteTrack выполняет трекинг. Он сопоставляет объекты на соседних кадрах и сохраняет за ними один и тот же ID. Благодаря этому программа понимает, что машина на разных кадрах - это один и тот же объект.

Подсчет выполняется по пересечению линии. Для каждого объекта вычисляется центр рамки. Если центр перешел с одной стороны линии на другую, ID объекта добавляется в список посчитанных.
